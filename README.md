# RBSS/RBSSS Dashboard

Interactive dashboard for Railway Board Secretariat Service (RBSS/RBSSS) orders and officer data.

## Features
- Search officers by name, designation, section
- Filter by year, order type
- Browse all 1600+ extracted records
- Source PDF links

## Data
Extracted from 1013 RBSS/RBSSS order PDFs using MiMo v2.5 Pro OCR pipeline.
